HARZ Cloud API Documentation

The developer platform for Africa. 118 endpoints across 18 service categories.

https://harz-cloud-backend.vercel.app
Authentication: Most endpoints require an auth token. Pass it via the x-auth-token header.
Get a token: POST /api/sso/login {"platform":"your-app","userId":"user123"}

Core Endpoints

GET /api/stats
Get ecosystem-wide statistics: platforms, repos, agents, revenue.
Response
{ "platforms": 49, "live": 48, "repos": 62, "agents": 7, "revenue": 125000, "wallet_balance": 89000 }
GET /api/platforms
List all 49 platforms in the HARZ ecosystem.
Response
[ { "name": "HarzPay", "icon": "💳", "category": "Finance", "url": "https://harzpay.vercel.app", "status": "Live", "revenue": 12000 }, ... ]
POST /api/platforms
Add a new platform. Requires auth.
Request Body
{ "name": "NewApp", "icon": "🚀", "category": "AI", "url": "https://newapp.vercel.app", "description": "A new HARZ platform" }
GET /api/agents
List all 7 AI agents with their roles and specialties.
Response
[ { "name": "Magani", "role": "Health Agent", "icon": "🏥", "status": "active", "success_rate": 98.5, "tasks_completed": 1247 }, ... ]
GET /api/wallet
Get wallet balances across all currencies.
Response
{ "ngn_balance": 89000, "usd_balance": 450, "gdeg_balance": 0, "usdt_balance": 120 }
POST /api/wallet/transfer
Transfer funds between currencies. Requires auth.
Request Body
{ "from": "ngn", "to": "usd", "amount": 10000 }
GET /api/transactions
List all transactions with optional filters.
Query Parameters
?type=payment&status=completed&limit=50

Paystack Payments

POST /api/payments/initialize
Initialize a Paystack transaction. Requires auth.
Request Body
{ "email": "customer@example.com", "amount": 5000, // in Naira "reference": "HARZ_12345", // optional "callback_url": "https://yoursite.com/callback" }
Response
{ "status": true, "data": { "authorization_url": "https://checkout.paystack.com/...", "reference": "HARZ_12345", "access_code": "..." } }
GET /api/payments/verify/:reference
Verify a Paystack transaction by reference.
Response
{ "status": true, "data": { "status": "success", "amount": 500000, // in kobo "customer": { "email": "customer@example.com" } } }
GET /api/payments/list
List Paystack transactions. Requires auth.
Query Parameters
?perPage=50&page=1&from=2026-01-01&to=2026-12-31
POST /api/payments/refund
Refund a Paystack transaction. Requires auth.
Request Body
{ "reference": "HARZ_12345", "amount": 2500 // optional, partial refund }

GitHub Integration

GET /api/github/repos
List all repositories in the HARZ ecosystem (60+ repos).
Query Parameters
?sort=updated&per_page=100
GET /api/github/repos/:repo/issues
List issues for a specific repository.
Example
/api/github/repos/harz-cloud-backend/issues?state=open
GET /api/github/repos/:repo/commits
List recent commits for a repository.
GET /api/github/repos/:repo/pulls
List pull requests for a repository.

Channel System

GET /api/channels
Get status of all messaging channels (WhatsApp, Slack, Telegram, iMessage).
POST /api/channels/send
Send a message via a channel. Requires auth.
Request Body
{ "channel": "whatsapp", "to": "+2348012345678", "text": "Hello from HARZ Cloud!" }
POST /api/channels/route-test
Test agent routing for a message.
Request Body
{ "text": "I have a headache" }
Response
{ "agent": "Magani", "role": "Health Agent", "confidence": 0.95, "language": "en" }

Infrastructure

GET /api/deployforge
Get DeployForge orchestration dashboard data.
GET /api/scheduler/tasks
List scheduled tasks.
POST /api/scheduler/tasks
Create a scheduled task. Requires auth.
Request Body
{ "name": "Daily Report", "cron": "0 9 * * *", "action": "send-report" }
POST /api/orchestrator/tasks
Create an orchestrator task for agent delegation. Requires auth.
POST /api/backup/run
Run a full backup of all entity data. Requires auth.

Security

POST /api/sso/login
Create an SSO session and get JWT token.
Request Body
{ "platform": "harzstore", "userId": "ahmad" }
Response
{ "access_token": "eyJhbG...", "expires_in": "7d" }
POST /api/sso/verify
Verify an SSO token.
Request Body
{ "token": "eyJhbG..." }
POST /api/2fa/setup
Set up 2FA for a user. Requires auth.
Response
{ "qr_code": "otpauth://...", "secret": "ABCD1234EFGH5678" }
GET /api/keys
List API keys for the authenticated user. Requires auth.
POST /api/keys
Create a new API key. Requires auth.
DELETE /api/keys/:id
Revoke an API key. Requires auth.
