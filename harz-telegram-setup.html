Telegram Bot Setup

Connect your HARZ Cloud agents to Telegram

⏳ Telegram bot not connected yet. Follow the steps below.

Step 1: Create your bot

Use Telegram's BotFather to create a new bot and get your token.

1

Open @BotFather on Telegram

Search for @BotFather in Telegram and start a chat.

2

Create a new bot

Send /newbot and follow the prompts. Choose a name like "HARZ Cloud Bot" and a username like harz_cloud_bot.

3

Copy your bot token

BotFather will give you a token that looks like 123456789:ABCdefGHIjklMNOpqrsTUVwxyz. Paste it below.

Step 2: Set webhook

Your bot is connected! Now set the webhook so HARZ Cloud can receive messages.

https://harz-cloud-backend.vercel.app/api/channels/telegram/webhook

Or set it manually via:
https://api.telegram.org/bot/setWebhook?url=https://harz-cloud-backend.vercel.app/api/channels/telegram/webhook

Step 3: Your agents are ready!

These HARZ Cloud agents will respond to messages on your Telegram bot:

🏥 Magani Health Agent
🛡️ CyberShield Security Agent
⚡ Omega Commander DevOps Agent
🧘 Stillness Wellness Agent
📚 HarzLearn Education Agent
💰 HarzPay Finance Agent
🏗️ HarzBuild Builder Agent

HARZ Cloud Integration

Your Telegram bot will route messages to HARZ Cloud's Agent Router, which automatically selects the best agent based on message intent.

Flow:
User sends message → Telegram Webhook → HARZ Cloud Agent Router → Agent processes → Response sent back via Telegram
