📦 HARZ SDK Packages

🟢 npm @harz/sdk

JavaScript/TypeScript SDK for HARZ Cloud API

// Install npm install @harz/sdk // Usage import { HarzClient } from '@harz/sdk'; const harz = new HarzClient({ apiKey: 'your-api-key' }); // List platforms const platforms = await harz.list({}); console.log(platforms);

🐍 Python harz-sdk

Python SDK for HARZ Cloud API

# Install pip install harz-sdk # Usage from harz import HarzClient harz = HarzClient( api_key='your-api-key' ) # Deploy template result = harz.deploy( template_id='tmpl-001', app_name='My Store' ) print(result)

⌨️ HARZ CLI

# Install globally npm install -g @harz/cli # Initialize a new project npx harz init my-app # Create from template npx harz create --template ecommerce --name "My Store" # Deploy to production npx harz deploy --provider github-pages # Check health npx harz health # List all platforms npx harz list # View analytics npx harz analytics --period 30d
